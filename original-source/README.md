# R & K Muffler

Public, account-free business website for R & K Muffler, Lawndale, California.

## Source
- `dist/index.html`: page content, accessible dialogs, metadata and business schema.
- `dist/styles.css`: responsive styling, mobile contact bar, reduced-motion support.
- `dist/app.js`: navigation, service details, private call planner, clipboard controls.
- `dist/assets/`: locally hosted photos, fonts and favicon.
- `.openai/hosting.json`: deployment configuration.

This is a buildless site with no package installation, server, account provider or database. The full deployed source is preserved in the Site's Git repository. The audience is public. No ChatGPT sign-in is used by the application.

## Customer actions
Call links use +1 310-691-9772. Directions and reviews open Google Maps. The visit planner validates vehicle information and creates copyable call notes; it never claims to submit a request or confirm an appointment. Information stays in memory and is cleared when the planner closes. Scheduling, final quotes and availability are arranged by telephone. There is no messaging integration or automated booking backend because the business has not provided one.
